# PrimeCircle AI Company

This folder is an isolated starter workspace for the PrimeCircle AI Company project.

## Quick start

- Open the folder in VS Code
- Run a local preview server from the project root
- Commit and push to GitHub when you are ready

## Suggested local preview

If Python is available:

```bash
python -m http.server 3000
```

Then open http://localhost:3000
