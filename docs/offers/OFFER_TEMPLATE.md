# Commercial Offer — [Name]

Copy this file per candidate offer (e.g. `offers/2026-07-funeral-home-intake.md`).
An offer is not validated until it has real evidence, not just a plausible story.

## Problem

What specific, painful, recurring problem does this solve? For whom?

## Target Customer

Who exactly buys this? How do they currently solve the problem (including
"they don't")?

## The Offer

What do they get, in plain language? What's included / not included?

## Price & Packaging

Price point, billing model (one-time / recurring), and why this price.

## Delivery Channel

How does this reach the customer, and how is it delivered/operated day to day?

## Founder Time Cost

Hours to deliver per customer, at launch and once semi-automated.

## Evidence / Validation Signal

What actually happened — conversations, pre-sales, waitlist signups, a paid
pilot — not hypothetical interest. Date each data point.

## Founder Filter

- Does it solve a real customer problem? —
- Can it generate revenue? —
- Does it save founder time (or is it worth the time it costs)? —
- Can an existing tool solve it (Buy/Integrate) before building? —
- Is this the smallest sellable version? —

## Verdict

Buy / Integrate / Configure / Automate / Build / Delay — and current status
(draft / testing / validated / abandoned).
