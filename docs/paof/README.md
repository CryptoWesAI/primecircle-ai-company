# PAOF Framework Docs

This is where PrimeCircle's AI Operations Framework (PAOF) methodology gets
written down as it's actually practiced — not aspirational documentation, but
notes distilled from real work on this project.

The immutable principles live in `../../PAOF_CONSTITUTION.md` and do not move.
This folder is for the *how*: one write-up per master-skill domain, added only
once there's a real artifact or decision behind it (see
`../../roadmap/LEARNING_ROADMAP.md`).

Master-skill domains (seeded, expand as work happens):

- Platform Architecture
- AI Automation Engineering
- AI Governance & Security
- Product & Business Design
- Platform Expertise (n8n, Supabase, Twilio, OpenRouter, Next.js, Docker, GitHub, etc.)
- Solution Design
- Founder Operations

No file per domain yet — create one (`platform-architecture.md`, etc.) the
first time there's real methodology to capture, not before.
