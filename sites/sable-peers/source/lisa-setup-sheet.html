01What Lisa will do on the page

The page has a Guide button in the corner. Today it speaks with the browser's own voice and opens topics on request. The moment your Agent ID is set, the same panel hands over to Lisa: the ElevenLabs widget loads and the page gives her six tools, so she can move the page while she talks: open a topic, switch the view, open a section of Sable's whitepaper on the map, search the whitepaper for a word, read today's sentence.

Context for the prompt: the Overview of the page is the Orrery, Sable's whitepaper drawn as a solar system. Thirteen sections turn around one sentence, every dot is a sentence of the paper, orange means it changed. Squares on the outer ring and a row of buttons under the map are the pages of the site: Explained, Try it (a simulation of the door), Verify (live status and a receipt checker), The field (eight peers compared), Token, Scenarios, Play (Gatekeeper, a game with a leaderboard), Log, Community.

Nothing from ElevenLabs loads until the ID is set. The panel tells visitors that their voice goes to ElevenLabs and that nothing goes to Sable.

What I need from you: the Agent ID of Lisa (it looks like agent_01…; ElevenLabs → Conversational AI → Agents → Lisa, shown on the agent page and under Widget) and a yes on the checklist below. Send it to me on Telegram or X (@0PTIMUS_ONE).

02Checklist in ElevenLabs

  1. Public agent, authentication off. Security tab: leave "Enable authentication" off. Under Allowlist, add sable.primecircle.cloud. The site is static and cannot sign sessions; the allowlist is what keeps the agent from being embedded elsewhere.
  2. First message: paste the text in section 03.
  3. System prompt: paste the text in section 03. It replaces the current one for this agent only. If Lisa also serves lisaonsable.com, make a copy of the agent for the Observatory first, so both keep their own prompt.
  4. Six client tools: add them under Tools, type Client, exactly as in section 04, with "Wait for response" on for all six. The page implements them; ElevenLabs only needs the names and parameters.
  5. Voice and language: Lisa's own voice, English.
  6. A limit on minutes. Every conversation on the site spends this account's minutes. Set a daily cap (the wording in the dashboard varies by plan; a maximum conversation duration and a daily limit both help) so a busy day stays cheap.
